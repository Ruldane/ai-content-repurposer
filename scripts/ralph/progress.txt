## US-009 through US-029: Full feature verification and bug fixes
Status: DONE
Notes: All features US-009 to US-029 were already implemented in code but marked as passes: false. Verified and fixed the following critical bugs:

### Critical Bugs Fixed:
1. **AI streaming (lib/ai.ts)**: @ai-sdk/anthropic appends /messages to baseURL, but Z_AI_BASE_URL already included /messages. Fixed by stripping /messages suffix from env var.
2. **Stream protocol mismatch (hooks/useRepurpose.ts)**: useCompletion from @ai-sdk/react v3 defaults to data stream protocol, but API returns text stream. Fixed by adding streamProtocol: 'text'.
3. **Hydration error (hooks/useLocalStorage.ts, hooks/useSettings.ts)**: useState initialized from localStorage during SSR caused hydration mismatch. Fixed by deferring localStorage read to useEffect with isInitialized ref guard.
4. **A/B variant generation (US-029)**: Generate Variant button only toggled view without triggering generation. Fixed by adding handleVariantGenerate in page.tsx that calls generate() with modified prompt, managing variant B state at page level, and passing variant content/callbacks to OutputEditor.
5. **Custom format API support (app/api/repurpose/route.ts)**: Added support for custom format system prompts alongside built-in formats.
